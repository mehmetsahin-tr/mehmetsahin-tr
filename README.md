# Hi, I'm Mehmet Şahin 👋

**Clinical research operations × software.** I build practical, privacy-first tools for research sites and CROs.

I spent many years on the operations side of clinical research: running studies, coordinating teams, and keeping GCP documentation inspection-ready. My background is in medical laboratory sciences and paramedicine, and over time my work moved steadily toward technology. Today I turn that field experience into software that removes paperwork, spreadsheets and guesswork from everyday research operations.

---

### 🔬 What I'm building

**[TrialGrids](https://trialgrids.com)**
Web-based tools for small research centers and CROs, designed around how clinical studies actually run on site.

**[TMF Control List](https://github.com/mehmetsahin-tr/trial-master-file-control-list)** · [▶ Use online](https://mehmetsahin-tr.github.io/trial-master-file-control-list/)
A free, open-source Trial Master File checklist for BE/BA studies. Single file, works offline, no sign-up. Section-level check and lock with edit history, PDF/DOCX attachments, export/import between computers and an A4 sign-off report. All data stays in the user's own browser.

---

### 🧭 What I care about

- **Tools shaped by the field:** built from real study workflows, not from assumptions about them
- **Privacy by design:** clinical data should stay where it belongs; my tools run locally and send nothing to a server
- **Simple over clever:** a site coordinator should be productive in five minutes, without training

`TypeScript` · `JavaScript` · `HTML/CSS` · `AI-assisted development` · `GCP / ICH E6 documentation workflows`
